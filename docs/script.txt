AI 幫我剪完一整支影片：7 個免費工具 + 1 份剪輯規範
【預計時長】約 10–11 分鐘（約 2700 字）
【標記說明】【R1】= 對應錄屏清單；【畫面】= 我在剪輯裡做的畫面；【待確認】= 需要你拍之前定下來

hook
哈嘍大家好。
現在大家看到的這支影片，從剪輯、字幕、動畫到配樂，全部都是 claude幫我剪的。
我一下時間線都沒有碰過喔。
【畫面：開頭快速閃 3 個動畫效果——標題彈出、數字跳動、截圖放大】
我這次只用到了 Claude 會員，剩下用到的工具，全部免費。今天就給大家全部免費分享。
最近外網有非常多的剪輯教程，教你用 Claude Code 搭一套自動剪輯系統，但裡面經常會有好幾個工具是要按月付費的。
所以這期，yomi老師就把它換成了一套全免費的中文版本。
用哪幾個工具、怎麼教會它你的剪輯風格、最後到底花多少錢，我今天一次講清楚。
如果你也是一個人做影片，被剪輯拖垮過，這期一定要看完。


以前要做一支這樣的影片，其實需要一個小團隊。
現在呢，我只負責兩件事：開機錄，還有給claude一些意見。
剩下的工作，我把它拆成了七個角色，每個角色負責一個工具。
我們一個一個來看。
【畫面：七個角色的卡片，講到哪個亮哪個】

第一個：剪輯師
第一個是剪輯師。
就是那個坐在時間線前面好幾個小時，一條一條看素材，挑能用的、刪掉講錯的，決定哪裡放大、哪裡加動畫的人。
在我這套系統裡，這個人就是 Claude Code本身。
你可以把它理解成整支影片的專案經理。
我用的是 Claude 的桌面版，它可以直接在我自己的電腦上幹活：讀我的素材、呼叫其他軟體、最後把成片放回我指定的資料夾。
後面講到的所有工具，都是由它在指揮。
【R1】

第二個：聽寫員
但是問題來了，Claude 它是聽不到影片聲音的。
那它怎麼知道我講了什麼，哪一句講錯了呢？
這就需要第二個角色：聽寫員。把素材裡的每一句話變成文字，再打上時間碼。
國外很多教程裡用的是英偉達的 Parakeet，免費，但是它不支援中文版本。
所以我換成了 Whisper，這是 OpenAI 開源的語音識別模型，可以直接在自己電腦上跑，中文也很準，同樣完全免費。
如果你平時習慣用剪映，直接匯出一份字幕檔案給它也可以，還更快。
有了帶時間碼的文字稿，Claude 就能對著我的腳本，一句一句找出我講得最好的那一條。

第三個：動畫師
第三個角色是動畫師。
片頭標題、彈出來的 logo、數字跳動這些動畫，以前要專門開 After Effects 去做。
現在我用的是 HyperFrames，HeyGen 開源的一個免費工具。
它的原理很有意思：Claude 先把每一個動畫寫成一個小網頁，HyperFrames 再把這個網頁錄成影片。
全部在我自己電腦上跑，不花錢。
而且 Claude 在剪的時候，我可以在 HyperFrames 裡面實時看到它剪到哪裡了。
【R7】

第四個：資料員
第四個是資料員。
我做crypto和 AI 的內容，經常會講到某某公司剛剛公佈了什麼。
這個時候，畫面上最好直接放出證據：官方公告、推文、新聞的截圖。
這個工作我交給瀏覽器。Claude 會自己開啟網頁去截圖，把重點那一行標出來、放大。
而且我給它定了一條死規矩：只能用真實的截圖，不準自己編推文、編新聞。
【畫面：真實網頁截圖 → 高亮一行 → 放大】

第五個：錄屏
那好，第五個是錄屏。
我很多影片都要邊講邊操作電腦。

我這次用的是 Openscreen，一個開源的免費錄屏軟體。
它可以同時錄螢幕和我的攝像頭，而且會分成兩個檔案存下來。
這樣 Claude 剪輯的時候，就可以把我的頭像做成一個小圓窗疊在錄屏上面，該放大的地方幫我放大，效果一樣，一分錢不花。
【畫面：錄屏 + 右下角圓形人像，演示一次放大】

第六個：音效師
第六個是音效師。
哪一段配什麼音樂，什麼時候加一個音效。
國外教程裡用的是 Epidemic Sound，也是按月付費的。
我用的是 YouTube 音訊庫，就在你自己的 YouTube 後臺裡面，免費，而且版權是安全的。
【R8】
我自己的習慣是：開頭放一點有懸疑感的音樂，進入正文換成很輕的背景音樂，音量壓得很低，不搶我的聲音。

第七個：質檢
最後一個是質檢。
把所有素材拼起來，檢查有沒有黑屏、聲音和畫面有沒有對不上。
這個用的是 FFmpeg，一個已經做了二十多年的免費開源工具，市面上很多剪輯軟體的底層其實都在用它。

最關鍵的：剪輯規範
好，七個工具講完了。
但是你有沒有發現，這七個工具，沒有一個知道我的影片應該長什麼樣。
這個才是整套系統裡最關鍵的東西。
在 Claude 裡面它叫 skill，你可以把它理解成一份剪輯規範。
Claude 每次開剪之前，都會先把它讀一遍。
裡面寫的就是我的個人風格：字幕什麼顏色、logo 放在哪裡、句子之間留多少空隙、音樂開多大聲。
【R5】
而且這份規範不是我自己寫的，是 Claude 在一次一次被我挑毛病的過程中，自己整理出來的。
我念幾條給大家聽：
同一句話我錄了好幾遍，就用最後一條講完整的。
句子和句子之間，留 0.2 秒。
提詞的口令、講錯的、罵人的，全部刪掉。
粗剪的時候先不動畫面，只管把話剪順。

怎麼教會它你的風格
工具都準備好之後，真正花時間的是調教。
我的方法是，先從短的開始，比如說只剪一個開頭。
它剪完一版，我就帶著時間碼給它意見。
比如說：第 22 秒這裡字幕太大了。這一句刪掉。
改完之後，最關鍵的一句話你一定要說：
把你剛剛學到的這些東西，記進剪輯規範裡。
這樣下一次，它就不會再犯同樣的錯了。
每剪一支，它就更懂你一點。

裡面有大量的重錄、口誤、停頓。

最後出來一條 16 分鐘的粗剪，一共切了 369 刀。

【R6】
當然，它不是一次就完美的。
我看完給它幾條意見，它改，再讓它把意見記進規範。
我是導演，Claude 是我的剪輯師。

到底花多少錢
最後是大家最關心的：成本。
我用的就是最基礎的 Pro，一個月 22 美元。
我平時寫腳本、做研究也全靠它，所以剪輯基本上算是附帶的。
很多國外教程，開的都是 200 美元一個月的頂配，再加上錄屏和音樂兩個訂閱。
我這套用 Pro 就跑得動，今天剪完一整支 16 分鐘的粗剪，這一週的額度也才用掉三分之一左右。
Whisper、HyperFrames、FFmpeg，全部免費開源。
錄屏用開源的 Openscreen，音樂用 YouTube 音訊庫，也是免費的。
所以算下來，除了 Claude 會員，額外的花費是零。
但對我來說，比省錢更重要的是速度。
以前一支影片從拍完到上線，要等好幾天。
現在當天拍、當天剪，當天就能發出來。
就像你現在看到的這一支。
