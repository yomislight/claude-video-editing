## 二、以後每一期的剪輯流程（SOP）

```
選題 → 腳本(你審) → 拍攝 → 交素材 → 粗剪(你看) → B-roll 清單(你審) → 精剪 → 質檢 → 交付 → 上傳(你確認) → 覆盤寫進規範
```

| 步驟 | 誰做 | 做什麼 | 產出 |
|---|---|---|---|
| 0. 腳本 | 我寫，你審 | 真人主播口吻，分段，標好要錄屏/要截圖的位置 | `腳本.txt` |
| 1. 拍攝 | 你 | A-roll 橫屏 16:9；按錄屏清單錄屏 | 原片 MOV + 錄屏 MOV |
| 2. 交素材 | 你 | 全部放進同一個資料夾，告訴我路徑就行，不用上傳 | `Desktop/影片/<日期_主題>/` |
| 3. 粗剪 | 我 | 轉寫（或用你的剪映 SRT）→ 對著腳本，每句取**最後一條講完整的** → 刪提詞口令、口誤、罵人 → 句間留 0.2 秒 → 不動畫面 | `粗剪.mp4` + `剪輯單.md` + FCPXML + Premiere XML；剪的過程你可以在 HyperFrames Studio 實時看 |
| 4. 粗剪反饋 | 你 | 帶時間碼說意見（格式見下面） | — |
| 5. B-roll 清單 | 我列，你審 | 時間碼 / 臺詞 / 型別 / 素材 / 來源。說到什麼就出什麼 | `B-roll清單.md` |
| 6. 精剪 | 我 | 截圖 B-roll、錄屏畫中畫、標題動畫、白字黑邊字幕、logo 右上角、音樂（hook 懸疑 → 正文輕音樂壓低）、少量音效 | `精剪.mp4` |
| 7. 質檢 | 我（FFmpeg） | 檢查黑場、音畫同步、響度約 -14 LUFS、爆音 | 質檢報告 |
| 8. 交付 | 我 | 成片 + 封面 + 標題/簡介/章節時間戳/標籤 | `成片.mp4`、`封面.png`、`標題與簡介.md` |
| 9. 上傳 | 我準備，你確認 | 先以「不公開」上傳，你看過再改「公開」。**釋出前我一定先問你** | YouTube 連結 |
| 10. 覆盤 | 你說，我記 | 「把這條記進剪輯規範」→ 下次不再犯 | 規範檔案更新 |

### 給意見的格式（越具體越快）

```
02:15 這句刪掉
03:40–03:52 這裡換成錄屏 R4
05:10 字幕太大，以後都小一號   ← 加「以後都」我就記進規範
```

## 三、今晚拍攝要準備的

### 裝置
- 相機/手機橫屏 16:9，和上次幣安那期一樣的機位就行
- 領夾麥（聲音比畫面重要）
- 提詞器放腳本；**同一句講錯了就停一下重講一整句**，我會自動取最後一條

### 錄屏清單（腳本里標了 R1–R8）
用 **Openscreen** 錄（開啟攝像頭，人臉會單獨存一個檔案，我拿來做右下角圓形頭像）。錄完不用匯出，告訴我錄了哪幾段就行，我直接去它的錄影資料夾拿原始檔案。

| 編號 | 錄什麼 | 大概長度 |
|---|---|---|
| R1 | Claude 桌面版 → Code 頁面，慢慢掃一遍介面 | 15 秒 |
| R2 | 選本地資料夾、許可權改「自動」、選模型 | 20 秒 |
| R3 | 輸入搭建指令（腳本里那句），它開始自動安裝 | 30 秒 |
| R4 | 把素材拖進對話方塊，輸入「照著腳本粗剪」 | 20 秒 |
| R5 | 開啟剪輯規範檔案，慢慢往下滾（**今晚先跳過**：拍完我做好 skill 檔案，再補錄這一段） | 15 秒 |
| R6 | 用 Premiere 開啟我匯出的 XML，時間線上一刀一刀的 | 15 秒 |
| R7 | HyperFrames Studio 裡實時看剪輯進度 | 20 秒 |
| R8 | YouTube Studio → 音訊庫頁面 | 10 秒 |

**錄屏前**：關掉郵箱、微信通知、錢包、任何 API key 和密碼；瀏覽器書籤欄收起來。

### 音樂
- 我從 YouTube Studio → 音訊庫裡挑，只挑「不需註明出處」的曲目；下載前把曲名列給你確認

## 四、上傳 YouTube

我這邊準備好：成片 mp4、封面、標題、簡介（含章節時間戳）、標籤。
上傳方式二選一：
1. **你拖進 YouTube Studio**（最穩，2 分鐘）：我把每個欄位都寫好，你複製貼上；
2. **我來傳**：需要你在內建瀏覽器裡登入 YouTube Studio，我以「不公開」上傳，你確認後再改公開。

不管哪種，**點「釋出」之前我都會先停下來問你。**
