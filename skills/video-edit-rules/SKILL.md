# 剪輯規範

> 有兩個版本：下面幾節是版本 A（新聞片，預設）；教程片照「版本 B：教程片」。
> **開剪前先看同一個資料夾有沒有 `LOCAL.md`**：裡面放本機路徑、頻道設定、現成工程的位置。有就先讀，內容以它為準。它只留在自己電腦，已寫進 `.gitignore`，不上傳。

## 粗剪
- 同一句話錄了好幾遍，用最後一條講完整的
- 句子和句子之間留 0.2 秒
- 提詞的口令、講錯的、罵人的，全部刪掉
- 句子裡的語氣詞全部刪掉：嗯、呃、額、啊、呀、哎、誒、唉、哦（「總額」這類詞裡的字不算）
- 重講、重複的半句一定要清乾淨；交片前用 FunASR 逐字查，不能靠 Whisper
- 口播裡念的「第一步／第二步／最後一步」要保留、念出來（剪掉會太急促），章節卡跟著這句口播一起進；字幕照念的字上。成片已剪掉的話，從原片按幀切回來（畫面＋原聲，接在下一段起點前，無縫），時間換算時插入點上的章節卡對齊到補回口播的開頭
- 刀口不能切到相鄰的字，句尾最後一個字要完整（「列好」「股價」「拜拜」都切壞過）
- 句和句之間的自然停頓不要壓得太短，聽起來急就留原本的停頓
- 粗剪的時候先不動畫面，只管把話剪順
- 我給的字幕檔案優先，不用從頭轉寫
- 每次都匯出 mp4、Premiere XML、FCPXML、剪輯單

## 字幕
- 繁體，全片跟讀，一屏一行
- **字型一律用漢儀節奏黑（`HYJieZouHeiF.ttf`）**：字幕、標題、卡片大字都用它；只有說明小字用阿里巴巴普惠體。做法見下面「字型」。
- 56px 白字加柔和陰影（不加黑描邊），關鍵詞用主色
- 產品名按官方寫法：Claude、HyperFrames、FFmpeg

## 畫面
- 說到什麼就出什麼；沒有具體名詞的句子不放素材
- 動畫放在人兩邊的牆面，左右交替，人往反方向讓位，不能擋臉
- 網頁截圖、後台畫面這類證據全屏切出 3–6 秒，放在深色底圓角視窗；概念動畫才放人兩邊
- 人像刀口在 100%／115% 兩種景別間輪換，遮跳剪，以人臉為中心推近
- 開頭前 20 秒 3–5 秒換一次畫面；金額用全屏大數字；提示詞用逐字打出的卡片，關鍵詞上主色
- 並列多項用清單卡（沒講到的先模糊，講到哪條亮哪條）；並列的平台／產品用橫排卡片，講到的發光
- 結尾要不要放 CTA 網址條、訂閱動畫、片尾卡，照頻道設定；教程片不放
- 錄屏：圓角人像卡放左邊，視窗放右邊，人臉在卡片正中
- **口播一提到公司、產品、AI 工具、股票（ChatGPT、Claude、Grok、NVIDIA、AMD……），畫面上就要出現它的官方 logo**：明顯的 logo 磁貼或角標，不能只靠網頁裡的小圖示；截圖視窗也要配上該產品的 logo
- **logo 要按構圖擺，像專業剪輯師一樣考慮整個畫面**：放在畫面的留白處，跟主要元素對齊，不要貼在人像卡、人臉或截圖上當小角標。例：左人像卡＋右截圖窗時，「logo＋產品名」做成截圖窗上方的標題，左邊對齊視窗左緣，標題頂端對齊人像卡頂端，視窗底對齊人像卡底；同一個資訊不要在畫面上重複出現兩次
- 只用真實截圖，不準編推文、編新聞
- **口播講到關鍵股價（某支股票跌了幾 %、收盤價、從高點跌了幾成），一定放真實 K 線**：TradingView 官方嵌入圖表的日線截圖（`scripts/chart_shot.mjs`），框出那一根 K 線，右上標籤寫真實數字和日期。不准用自己畫的示意 K 線代替

## 聲音
- 精彩預告和開場 hook 放懸疑感的音樂；**從頻道片頭開始，正文主要用 funk**（幾首輪播到片尾），不要中途換風格。音量壓低：配樂整合響度比人聲低約 24 dB（人聲 -16 LUFS 時，配樂約 -40 LUFS）；寧可小，不要搶人聲
- 配樂只從我指定的音樂資料夾選，先做墊在口播下的試聽給我挑
- 音效只放在有動作的地方，不搶人聲
- 成片響度約 -14 LUFS

## 流程
- 先給我看樣片，確認風格再做全片
- 我在 Studio 裡拖過的位置，要讀出數值寫回建置腳本，不然重建會被蓋掉
- 頻道 logo 全片同一個位置，座標只寫一處
- 長片渲染用 `--workers 1`，詳見 news-event-longform
- 詳情頁另存純文字 txt，章節每行一個、從 0:00 開始
- 生圖提示詞一律中文
- 我說“記進規範”，就把意見寫進這份檔案
- 上傳前一定先問我

## 版本 B：教程片
深色、剋制、以真實錄屏為主的教程片。參考 Christian Peverelli 的剪法，可對照 `episode/` 裡的公開範例。粗剪、質檢、交付流程照版本 A。
- **人像**：人在正中間全屏。出卡片時人往反方向讓位（x ±120、推近到 1.14 倍），卡片走了回正。沒有卡片的句子偶爾推近 1.1 倍遮跳剪。
- **字幕**：跟版本 A 一樣，全片跟讀、繁體、一屏一行，節奏黑 54px，關鍵詞上主色。**節奏黑要餵簡體字**（字型自己畫成繁體），打繁體字會掉成別的字型；一簡多繁的字用 MiSans Heavy 補，清單看下面「字幕」。普惠體的說明小字才直接打繁體。
- **主色**：青綠 `#5EEAD4`，底色 `#07090f`。
- **配樂**：全片 funk（冷開場也是），不用懸疑配樂；先做墊在口播下的試聽再定。音量用「人聲實測響度 − 24 dB」去算每首的增益，不能拿曲子本身的響度去減，否則會算大很多。冷開場沒口播時可以大聲，口播一開始就壓下來。
- **音效**：Mixkit 幾個固定的就夠（卡片出現、切畫面、亮起、數字各一個），只放在有動作的地方，同一刻不疊兩個。
- **從參考片學的四點**：
  1. **議程卡**：hook 之後放一張「IN THIS VIDEO」，跟著口播一條一條加上去。
  2. **骨架反覆出現**：並列重點做成進度清單（例如 5 THINGS、6 TOOLS），每講到下一項就再出一次：講過的打勾、當前項亮、其餘灰。
  3. **平常畫面乾淨**：開場照樣密（3–5 秒換一次）；正文沒有具體名詞的句子放人，但**只有人的畫面連續不超過 7 秒**（建置腳本要列出來，再補畫面）；同一時間只出一張卡。
  4. **真實畫面放大**：網站、軟體操作放在大的深色 Mac 視窗，幾乎佔滿畫面，字要看得清。
- **冷開場**：成品的快剪放在打招呼之前，或直接鋪在打招呼底下，前 12 秒一定看到成品；最帥的動作跟著口播走（說轉就轉、說拆就拆）。
- **logo**：工具一出現就配官方 logo，照上面的規則擺。片中說過不放 logo 的品牌、有商標疑慮的品牌，只用文字。
- **片尾**：不放 CTA 網址條、訂閱動畫、片尾卡。

### 素材：少放文字卡，多放真的畫面
- 優先順序：真實操作錄屏 → 官方頁面錄屏 → 真實截圖 → 數字卡 → 文字卡。能錄到真的，就不做卡片。
- 講價格、額度、授權、免費版限制：錄官方頁面，滾到那一行，用框標出來，其餘壓暗。
- 講「怎麼跟 AI 說」：錄真的在工具裡打字、貼提示詞，不用假對話框。
- 講自己的作品演變：每一版都留檔、重新打開錄一次（V1 → V8），不用口頭帶過。
- 抽象概念放真圖：講面數就放網格圖，講切塊就放分色圖。
- 錄屏要有游標、點擊和輕微推近；重點放在畫面左邊四分之三，不能被右下人像小框壓到。
- 錄網頁的規矩：不按外站的送出鈕；Cookie 橫幅只隱藏、不接受；網站擋自動瀏覽器就不繞過；畫面裡別人的頭像和名字、自己的帳號、信箱、金鑰一律打碼或裁掉。

### 好用的畫面樣式
| 樣式 | 用在 |
|---|---|
| 關鍵句放大＋emoji＋音效 | 一段的重點句；人推近 1.1、字一組一組彈出，這段不出字幕。全片 6–8 次就好 |
| 三格流程 | 一句話裡有先後三步，說到哪格出哪格 |
| 跳轉箭頭（大時間＋箭頭指向進度條） | 「會的人可以跳過」；時間要等於下一段的真實起點，改過粗剪要同步改 |
| 訂閱卡 | 開頭請大家訂閱：頭像＋滑鼠點一下變「已訂閱」，只放一次，不放片尾 |
| 社群卡 | 提到社群；成員頭像和名字一定打碼 |
| 版本縮圖格、來源縮圖格 | 一次講完幾個版本、每個設計的參考來源 |
| 左邊真網站、右邊清單逐條打勾 | 回頭對標準、做總結 |
| 兩個視窗並排 | 前後對比（隨口一句提示詞／給了參考的提示詞） |
| 框和標籤 | 在真實畫面上指出「就是這裡」 |
| 斜蓋印章「沒有用」 | 說某個做法是錯的 |
| 進度清單骨架卡 | 並列重點反覆出現，講到哪格亮哪格 |

### 字幕：文字要照粗剪後的聲音，不能用 Whisper 逐句稿
- Whisper 逐句稿是照原片切的，粗剪改過後會多出重複半句、也會漏句（一支 21 分鐘的片抓到過 10 處重複、5 處漏字）。
- 做法：粗剪聲音切成 10–16 秒短窗跑 FunASR → 手寫斷行（一行一屏，照語意斷，不斷在詞中間）→ 逐字對時間 → 再對一次口播。
- 口播的口誤字幕寫對的，其他照念的字上。
- 一簡多繁要補的字：後、幹、鬆、準、線、麼、裡、醜、於、餘、佔、並、餵；要看詞的：乾淨、複製、複雜、隻（一隻貓）、手錶、託管、壓桿、註冊、遊戲、關係。整片用 opencc 對過再交。
- 大字出現時藏字幕，前後 0.25 秒內的短字幕也要藏，不然會閃一下。

### 建置時自動防呆
- 滿版畫面之間 ≤0.12 秒的縫要自動補上，不然會閃一格全屏的人；人像小框的區間也一起補。
- 場景一進來就要有東西，不能先空著等卡片。
- 錄屏片段比檔案長時，尾巴用最後一格補足。

### 渲染前質檢
| 查什麼 | 怎麼查 |
|---|---|
| 字幕、小框、文字互相壓到或出畫 | 無頭瀏覽器逐 0.1 秒 seek，量每個可見元素的框 |
| 小框和滿版對不上、片段不夠長 | 按 30fps 每一格比對區間 |
| 空場景 | 每個場景剛進來時，數可見元素 |
| 字幕和口播不一致 | 用 FunASR 短窗結果對字幕 |
| 缺字、漏轉的簡體、一簡多繁 | 逐字查字型，再用 opencc 對一遍 |
| 響度 | 人聲、配樂、音效分開量 |
| 整片看過一遍 | 每 4 秒抽一幀拼總覽 |
| 渲染後 | 統一到 -14 LUFS，再查規格、靜音、黑屏 |

# 詳細做法

## 一、工作順序（每一步我確認了再往下）

| 步驟 | 做什麼 | 產出 |
|---|---|---|
| 1 | 看素材和腳本，列出還缺什麼 | 缺口清單 |
| 2 | 轉寫：優先用我給的 SRT；沒有再用 Whisper | 帶時間碼的文字稿 |
| 3 | 粗剪，同時在 HyperFrames Studio 裡開啟讓我看 | 粗剪 mp4、剪輯單、兩種工程檔案 |
| 4 | 我帶時間碼給意見，改到定稿 | 定稿粗剪 |
| 5 | 把定稿再轉寫一遍，用真實時間碼列 B-roll | `B-roll清單.md` |
| 6 | 做 30 秒風格樣片，用真實片段 | `風格樣片.mp4` |
| 7 | 做全片，Studio 裡隨時能看 | `hf_final/` |
| 8 | 我確認後才渲染 | 成片 mp4 |
| 9 | 統一響度、質檢、寫標題簡介 | 成片、封面、`標題與簡介.md` |
| 10 | 以「不公開」上傳；公開前必須問我 | 連結 |

## 二、轉寫和粗剪的坑

- Whisper 必須加 `-mc 0`，不要加 `--prompt`。否則可能從某一句開始無限重複。
- 轉寫完檢查有沒有連續相同的句子。
- 切完把成片再轉寫一遍，和腳本逐句對照，查殘留的半句。
- 不到 1 秒的短片段單獨聽一遍，這裡最容易留下語氣詞和半句話。
- 結尾最後一個詞要看音量，不能只信轉寫時間，否則會切掉半個字。
- 原片有水印或懸浮圖示時，先裁掉再做母帶，所有匯出都用這個母帶。
- 帶時間碼的意見要對回片段編號，先確認是哪一段再改。

### 逐字檢查
- **Whisper 會把口吃、重講的半句和語氣詞「洗掉」**，整段轉寫、單句轉寫都一樣，所以拿 Whisper 對腳本看不出重複和語氣詞。曾經因此在一支片裡漏了二十幾處重複、五十處語氣詞。
- 逐字轉寫用 FunASR Paraformer：`scripts/fasr.py in.wav out.json`（用裝了 FunASR 的 Python 環境跑），16 分鐘約 2 分鐘，每個字有時間。
- 重複：`scripts/repeats.py`（幾個字內又出現同一串）＋ `scripts/repeats2.py`（放寬版、單字結巴）。每條人工判斷：「一層一層」「怎麼申請怎麼設置」是正常說法，保留。
- 語氣詞：先對**原片**跑一次 fasr，`scripts/srcfillers2.py` 把每個語氣詞在前後 2 秒的短片段裡重新定位再刪（長音頻的逐字時間偶爾會偏一個字，直接用會刪錯字，曾刪掉「就」「也」）。刀口上的用 `scripts/cutfillers.py` 在粗剪上定位、跨刀口分兩段刪。和前一個字連讀的（如「我啊」）起點要往後挪，不然會連前一個字一起刪掉。
- 要刪的原片區間寫進 `drops.json`，要保住不被切的區間寫進 `fills.json`（例如句尾字、兩句之間要留的停頓），`scripts/drops.py` 在 build_edl 之後套用（先 fills 後 drops）。
- 長音頻 fasr 會自己疊字（「董董事會」「簡簡單」）或聽出不存在的「啊」，可疑處用 `scripts/fasr_many.py` 或 `scripts/anychars.py` 切 3–20 秒短片段再轉，消失就是誤報。
- 每次修完都重跑 fasr＋repeats＋fillers，直到只剩正常說法；交片前用成片 mp4 的聲音再跑一次。

## 三、視覺風格

參考：Christian Peverelli 那種深色、剋制、有質感的教程片。樣式檔案在 `assets/style.css`。

- **底色**：近黑 `#07090f`，加青色和靛藍兩團很淡的微光。
- **卡片**：玻璃質感、細描邊，只有當前項發光。
- **主色**：只用一個，青綠 `#5EEAD4`。不用黃字、紅字、亮綠。
- **動效**：淡入、滑入、緩慢推近。不抖動、不閃白、不彈跳。
- **錄屏**：裁掉側欄，只留主要內容，讓字看得清。
- **網頁**：3D 傾斜飄入，一行主色高亮，再緩慢推近，下方不能壓到字幕。
- **頻道標識**：確認是哪個頻道再決定 logo 和片頭片尾，不同頻道的素材不混用。

### 人像位置
- 不能擋的是**臉**，身體可以被遮擋。
- 不要把動畫放頭頂，也不要全部堆在正中間。
- 卡片放人兩邊的牆面，左右輪換。卡片在右，人就往左移。
- 用人臉定位（`scripts/facetrack.swift`）算出人臉位置，再擺人像卡，不靠目測。
- **人像小卡（右下）不能被任何卡片、截圖窗壓住**。卡片加 `box-sizing:border-box`，寬度才不會被 padding 撐出版面區；人像換位置要在素材淡入前移好，兩段素材貼太近來不及時，移動那一下把人像 z-index 提到素材上面。
- 交付前跑全片遮擋掃描（puppeteer 逐 0.1 秒 seek，量人像框和每個可見元素的重疊），掃到 0 處（或只剩幾 px 的印章角）才算過。

### 字型
- 標題和字幕用粗黑體；小字用好讀的黑體。
- 漢儀節奏黑繁體要**輸入簡體**才顯示繁體字形（字型裡只有簡體碼位）。一簡多繁的字（简体的「后、干、松、准、线、么、里」）會錯，要用 MiSans Heavy 單獨補上，全片逐句校對。
- 普惠體等其他字型沒有這個轉換，簡體輸入就顯示簡體，所以小字要真的轉成繁體。
- 自動做法：源文字一律寫簡體，建置完跑 `scripts/trad.py index.html`（需要 opencc，用 s2tw，只轉字形）。它在頁面加一段腳本，渲染前按每段文字實際的字型處理：不是節奏黑的整段換繁體；是節奏黑的保留簡體，只把一簡多繁的字換成 `<u>繁體</u>`（CSS：`u{text-decoration:none;font-family:"MiSans";font-weight:900}`）。
- 建置完用 `hyperframes snapshot` 抽幀，看「什麼」「線」這類字有沒有變對。
- 商業字型檔先確認授權。免費替代：MiSans Heavy、阿里巴巴普惠體、思源黑體。

## 四、真實素材

- 公司、產品、工具、股票名一律配官方 logo（從官網或維基共享資源取 SVG），出現時機對準口播；同一期的 logo 統一放 `assets/logos/`。
- 價格只用官網真實截圖，並記下抓取日期。價格可能和口播不同，要提前告訴我。
- 找不到真實素材就不放，絕不編造。
- 截圖時拒絕非必要 Cookie，不點接受。
- 只說看到的事實。比如倉庫已歸檔、價格變了，要主動告訴我。

## 五、聲音

- **絕對不要搞笑、古怪、滑稽的音樂。** 檔名帶 quirky、funny、playful 的直接排除。
- 用我指定的音樂資料夾。不確定的先做試聽檔案，等我確認。
- 音效風格：滑鼠單擊、嗖、發光、叮、輕彈跳、UI 滑動。
- 音效只用授權明確的免費來源（如 Mixkit），不要匯出剪映的素材來用。
- AI 聽不到聲音，音樂和音效的好壞必須交給我判斷，不能說“聽起來不錯”。

## 六、質檢

渲染後全部跑一遍：
- 幀數和時長與預期一致；畫面和聲音等長
- 沒有黑屏（`blackdetect`）
- 響度約 -14 LUFS，峰值不超過 -1.5 dBFS（`loudnorm`、`ebur128`）
- 抽幀檢查字幕、卡片、人臉有沒有互相遮擋
- 轉寫成片，查字幕和口播是否一致

如實彙報：看不到、聽不到、沒驗證的，都要直接說。
