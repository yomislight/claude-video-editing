# 剪輯規範

## 粗剪
- 同一句話錄了好幾遍，用最後一條講完整的
- 句子和句子之間留 0.2 秒
- 提詞的口令、講錯的、罵人的，全部刪掉
- 句子裡的語氣詞全部刪掉：嗯、呃、額、啊、呀、哎、誒、唉、哦（「總額」這類詞裡的字不算）
- 重講、重複的半句一定要清乾淨；交片前用 FunASR 逐字查，不能靠 Whisper
- 口播裡念的「第一步／第二步／最後一步」是章節標題，不剪進去，交給標題卡和 YouTube 章節；正文開頭的「第X步」只刪這幾個字，刪了不成句就整句刪
- 刀口不能切到相鄰的字，句尾最後一個字要完整（「列好」「股價」「拜拜」都切壞過）
- 句和句之間的自然停頓不要壓得太短，聽起來急就留原本的停頓
- 粗剪的時候先不動畫面，只管把話剪順
- 我給的字幕檔案優先，不用從頭轉寫
- 每次都匯出 mp4、Premiere XML、FCPXML、剪輯單

## 字幕
- 繁體，全片跟讀，一屏一行
- 白字加柔和陰影，關鍵詞用主色
- 產品名按官方寫法：Claude、HyperFrames、FFmpeg

## 畫面
- 說到什麼就出什麼；沒有具體名詞的句子不放素材
- 動畫放在人兩邊的牆面，左右交替，人往反方向讓位，不能擋臉
- 錄屏：圓角人像卡放左邊，視窗放右邊，人臉在卡片正中
- 英文工具名一律配官方 logo 或真實網頁
- 只用真實截圖，不準編推文、編新聞

## 聲音
- 開頭放一點懸疑感的音樂，正文換輕鬆的，音量壓低
- 音效只放在有動作的地方，不搶人聲
- 成片響度約 -14 LUFS

## 流程
- 先給我看樣片，確認風格再做全片
- 我在 Studio 裡拖過的位置，要讀出數值寫回建置腳本，不然重建會被蓋掉
- 頻道 logo 全片同一個位置，座標只寫一處
- 長片渲染用 `--workers 1`，詳見 news-event-longform
- 詳情頁另存純文字 txt，章節每行一個、從 0:00 開始
- 生圖提示詞一律中文
- 我說“記進規範”，就把意見寫進這份檔案
- 上傳前一定先問我

# 詳細做法

## 一、工作順序（每一步我確認了再往下）

| 步驟 | 做什麼 | 產出 |
|---|---|---|
| 1 | 看素材和腳本，列出還缺什麼 | 缺口清單 |
| 2 | 轉寫：優先用我給的 SRT；沒有再用 Whisper | 帶時間碼的文字稿 |
| 3 | 粗剪，同時在 HyperFrames Studio 裡開啟讓我看 | 粗剪 mp4、剪輯單、兩種工程檔案 |
| 4 | 我帶時間碼給意見，改到定稿 | 定稿粗剪 |
| 5 | 把定稿再轉寫一遍，用真實時間碼列 B-roll | `B-roll清單.md` |
| 6 | 做 30 秒風格樣片，用真實片段 | `風格樣片.mp4` |
| 7 | 做全片，Studio 裡隨時能看 | `hf_final/` |
| 8 | 我確認後才渲染 | 成片 mp4 |
| 9 | 統一響度、質檢、寫標題簡介 | 成片、封面、`標題與簡介.md` |
| 10 | 以「不公開」上傳；公開前必須問我 | 連結 |

## 二、轉寫和粗剪的坑

- Whisper 必須加 `-mc 0`，不要加 `--prompt`。否則可能從某一句開始無限重複。
- 轉寫完檢查有沒有連續相同的句子。
- 切完把成片再轉寫一遍，和腳本逐句對照，查殘留的半句。
- 不到 1 秒的短片段單獨聽一遍，這裡最容易留下語氣詞和半句話。
- 結尾最後一個詞要看音量，不能只信轉寫時間，否則會切掉半個字。
- 原片有水印或懸浮圖示時，先裁掉再做母帶，所有匯出都用這個母帶。
- 帶時間碼的意見要對回片段編號，先確認是哪一段再改。

### 逐字檢查（2026-11-11 AI美股那期學到的）
- **Whisper 會把口吃、重講的半句和語氣詞「洗掉」**，整段轉寫、單句轉寫都一樣，所以拿 Whisper 對腳本看不出重複和語氣詞。那期因此漏了二十幾處重複、五十處語氣詞。
- 逐字轉寫用 FunASR Paraformer：環境 `~/ai-tools/venvs/funasr`，`scripts/fasr.py in.wav out.json`，16 分鐘約 2 分鐘，每個字有時間。
- 重複：`scripts/repeats.py`（幾個字內又出現同一串）＋ `scripts/repeats2.py`（放寬版、單字結巴）。每條人工判斷：「一層一層」「怎麼申請怎麼設置」是正常說法，保留。
- 語氣詞：先對**原片**跑一次 fasr，`scripts/srcfillers2.py` 把每個語氣詞在前後 2 秒的短片段裡重新定位再刪（長音頻的逐字時間偶爾會偏一個字，直接用會刪錯字，那期刪掉過「就」「也」）。刀口上的用 `scripts/cutfillers.py` 在粗剪上定位、跨刀口分兩段刪。和前一個字連讀的（如「我啊」）起點要往後挪，不然會連前一個字一起刪掉。
- 要刪的原片區間寫進 `drops.json`，要保住不被切的區間寫進 `fills.json`（例如句尾字、兩句之間要留的停頓），`scripts/drops.py` 在 build_edl 之後套用（先 fills 後 drops）。
- 長音頻 fasr 會自己疊字（「董董事會」「簡簡單」）或聽出不存在的「啊」，可疑處用 `scripts/fasr_many.py` 或 `scripts/anychars.py` 切 3–20 秒短片段再轉，消失就是誤報。
- 每次修完都重跑 fasr＋repeats＋fillers，直到只剩正常說法；交片前用成片 mp4 的聲音再跑一次。

## 三、視覺風格

參考：Christian Peverelli 那種深色、剋制、有質感的教程片。樣式檔案在 `assets/style.css`。

- **底色**：近黑 `#07090f`，加青色和靛藍兩團很淡的微光。
- **卡片**：玻璃質感、細描邊，只有當前項發光。
- **主色**：只用一個，青綠 `#5EEAD4`。不用黃字、紅字、亮綠。
- **動效**：淡入、滑入、緩慢推近。不抖動、不閃白、不彈跳。
- **錄屏**：裁掉側欄，只留主要內容，讓字看得清。
- **網頁**：3D 傾斜飄入，一行主色高亮，再緩慢推近，下方不能壓到字幕。
- **頻道標識**：確認是哪個頻道再決定 logo 和片頭片尾。個人頻道不放加密未來的素材。

### 人像位置
- 不能擋的是**臉**，身體可以被遮擋。
- 不要把動畫放頭頂，也不要全部堆在正中間。
- 卡片放人兩邊的牆面，左右輪換。卡片在右，人就往左移。
- 用人臉定位（`scripts/facetrack.swift`）算出人臉位置，再擺人像卡，不靠目測。

### 字型
- 標題和字幕用粗黑體；小字用好讀的黑體。
- 漢儀節奏黑繁體要**輸入簡體**才顯示繁體字形。一簡多繁的字（简体的「后、干、松、准、线」）會錯，要用接近的字型單獨補上，全片逐句校對。
- 商業字型檔先確認授權。免費替代：MiSans Heavy、阿里巴巴普惠體、思源黑體。

## 四、真實素材

- 工具和產品名配官方 logo；從產品自己的網站取。
- 價格只用官網真實截圖，並記下抓取日期。價格可能和口播不同，要提前告訴我。
- 找不到真實素材就不放，絕不編造。
- 截圖時拒絕非必要 Cookie，不點接受。
- 只說看到的事實。比如倉庫已歸檔、價格變了，要主動告訴我。

## 五、聲音

- **絕對不要搞笑、古怪、滑稽的音樂。** 檔名帶 quirky、funny、playful 的直接排除。
- 用我指定的音樂資料夾。不確定的先做試聽檔案，等我確認。
- 音效風格：滑鼠單擊、嗖、發光、叮、輕彈跳、UI 滑動。
- 音效只用授權明確的免費來源（如 Mixkit），不要匯出剪映的素材來用。
- AI 聽不到聲音，音樂和音效的好壞必須交給我判斷，不能說“聽起來不錯”。

## 六、質檢

渲染後全部跑一遍：
- 幀數和時長與預期一致；畫面和聲音等長
- 沒有黑屏（`blackdetect`）
- 響度約 -14 LUFS，峰值不超過 -1.5 dBFS（`loudnorm`、`ebur128`）
- 抽幀檢查字幕、卡片、人臉有沒有互相遮擋
- 轉寫成片，查字幕和口播是否一致

如實彙報：看不到、聽不到、沒驗證的，都要直接說。

## 七、腳本（`scripts/`）

| 檔案 | 作用 |
|---|---|
| `build_edl.py` | `edl.txt` + `cues.json` + `audio16k.wav` → 精確切點 `segments.json` |
| `render.py` | 按切點拼聲音（`--audio-only` 只出聲音）；需要 `audio48k.wav` |
| `render2.py` | 逐段精確匯出畫面併合成粗剪 |
| `export_timeline.py` | 匯出 FCPXML 和 Premiere XML |
| `make_hf.py` | 生成 HyperFrames Studio 監看工程 |
| `make_sheet.py` | 生成剪輯單 |
| `make_caps.py` | 成片轉寫 → 校正後的字幕（`FIX` 表每期要改） |
| `facetrack.swift` | macOS 全片人臉定位 |
| `capture.mjs` | 抓真實網頁並定位要高亮的句子 |
| `fasr.py` | FunASR 逐字轉寫（不吞重複和語氣詞），輸出逐字時間 |
| `anychars.py` / `fasr_many.py` | 短片段逐字轉寫，用來精確定位、排除誤報 |
| `repeats.py` / `repeats2.py` | 找重講、重複的半句和單字結巴 |
| `fillers.py` | 列出逐字稿裡的語氣詞 |
| `srcfillers2.py` | 在原片短片段裡重新定位語氣詞，寫進 `drops.json` |
| `cutfillers.py` | 刀口上的語氣詞：在粗剪上定位、換算回原片 |
| `autodrop.py` | 把選中的重複換算成原片時間、對齊停頓，寫進 `drops.json` |
| `drops.py` | build_edl 之後套用 `fills.json`（保住）和 `drops.json`（刪除） |

環境變數：`SRC` 原片、`OUT` 輸出、`NAME` 工程名、`SRC_FRAMES` 原片總幀數。

`edl.txt` 每行一句，數字是字幕序號：`10-14` 連續幾條，`16[5:11]` 取一條裡的第 5–11 字，`@295.0-297.1=文字` 直接指定原片時間，`#` 是註釋。

依賴：FFmpeg、whisper.cpp、FunASR（`~/ai-tools/venvs/funasr`）、HyperFrames、Python（numpy）。
