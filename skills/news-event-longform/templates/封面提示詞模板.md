# 封面結構與提示詞模板（一律中文）

## 往期封面套路（加密未來）
- 人物：本人在右側或中間，半身，表情明確（震驚／微笑攤手），手勢指向重點，辦公室淺景深。
- 主角：左上角放這期主角的 logo 或道具，立體、有光澤。
- 箭頭：黃色或紅色粗箭頭把主角和人物／反派連起來。
- 大字：下半部兩行。第一行白字粗黑描邊；第二行黃橘漸層加黑描邊，是最大的字（約第一行 1.3 倍）。
- 文案：第一行寫事件和數字，第二行寫反轉，與主標題呼應但不重複。

## 人物圖
用 `scripts/stills.sh` 從**美顏版**影片抽 4 張候選 → 給使用者挑 → 存成 `封面素材/封面人物.png`。

## 版本 A：無字底圖（推薦，字在 Canva／剪映裡加）
```
YouTube 影片封面，16:9 橫版，1280×720，高對比、吸睛的科技新聞風格。
右側：參考上傳的人物照片（同一張臉、{髮型}、{服裝}），半身入鏡，{表情}，{手勢}，坐在辦公桌前，背景是明亮的現代辦公室，淺景深虛化。
左上：{主角 logo／道具的立體描述，加上「出事」的視覺：裂開、被打開的鎖、火花、紅光}。
左側中間：{反派或事件象徵，不放可辨識的真人或國旗}。
一個粗的亮黃色彎箭頭，從{A}指向{B}。
背景的螢幕上顯示{和主題相關的畫面，例如暴跌的紅色 K 線}。
畫面下方 40% 盡量留乾淨，用來放大標題字。
色彩飽和鮮明，人物對焦清晰，電影感打光，不要任何文字，不要浮水印。
```

## 版本 B：帶字（工具支援中文字時，接在 A 後面）
```
在畫面下方加上粗體繁體中文標題：
第一行（白色字、粗黑描邊、略微傾斜）：{事件＋數字}
第二行（最大的字，黃色到橘色漸層，粗黑描邊加投影）：{反轉句}
字體用特粗的圓體中文標題字，像台灣熱門 YouTube 封面那種風格。
確保每個中文字都正確，不要錯字。
```

## 注意
- 表情要和第二行文案配：微笑配「錢卻沒了？！」這種反差句，震驚配直白句。
- 涉及國家歸因的事件，封面用兜帽剪影，不放國旗、不放真人。
